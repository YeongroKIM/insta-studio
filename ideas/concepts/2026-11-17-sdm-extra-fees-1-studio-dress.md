# 스드메 추가금 1편 — 스튜디오·드레스에서 붙는 것들

## 훅 3안 (첫 장 / 첫 3초)
1. 스드메 추가금 1편: 스튜디오·드레스, 이 숫자만 알고 가세요
2. 드레스는 입어보기만 해도 돈이 들어요 (피팅비 중간 6만원)
3. 원본 22만·헬퍼 25만… 스드메 견적에 없던 돈 정리했어요

## 왜 저장하나
스튜디오·드레스 상담 때 "이건 얼마예요?"를 바로 대조할 항목별 중간가 표라서. 2편(메이크업·당일)과 시리즈로 모아 보게 됨.

## 놀람 포인트
스드메 관련 선택품목만 58종(스튜디오 17종, 드레스 11종 등)이 조사됐고, 드레스는 입어보기만 해도 피팅비가 붙는다(중간 6만원) (58종 B · 피팅비 A, 03 §4).

## 확인할 것
- ⏰ 모든 금액은 2025년 4월 소비자원 조사 중간가 → 게시 직전 참가격 최신 공개분으로 갱신 여부 확인 (격월 공개).
- 원본비는 다른 시점 보도에서 30만원(C) → 22만원(A)만 사용.
- 헬퍼비 "평균 29만원 이상" 보도(B/C 혼재)는 사용하지 않음. 헬퍼 교통·주차비는 항목 존재만 확인 → 넣지 않음.
- 58종 수치는 [1][2][7] 혼합 출처라 B로 표시 — 소비자원 원문 수치인지 확인하면 A로 올릴 수 있음.
- 표준계약서(2025.4)는 사실상 필수 품목(사진 파일·피팅비 등)을 기본서비스에 포함하도록 함(03 §2·§6, B) → 6편(총액 비교)과 연결되므로 여기서는 생략.
