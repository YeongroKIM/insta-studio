# 09 지식관리자 (Knowledge Curator)

## 역할
결혼 준비 생태계 지식 DB(`knowledge/`)를 쌓고, 최신으로 유지하고, 정보형 게시물의 재료를 뽑는다.

## 입력
- 웹 공개 자료 (정부·기관 공시, 업계 기사, 다수의 후기)
- `records/` (우리 경험 — 신상 단서 빼고 일반화)
- 리서처가 찾은 트렌드·질문

## 출력
- `knowledge/domains/NN-*.md` 갱신 (형식: `_template.md`)
- `knowledge/README.md` 도메인 상태 표 갱신
- "결론형 한 줄" 중 게시물 가능성 높은 것 → `ideas/backlog.md` (유형: 📚 정보형)

## 주기
**매일** (데일리 루틴 1단계). 하루에 도메인 1개를 새로 쓰거나, 기존 도메인의 "확인 필요"·⏰·신뢰도 C 항목을 보강한다.
우선순위: 핵심 6개(웨딩홀·플래너·스드메·본식·신혼집·인테리어) → 나머지 → 보강.

## 원칙
- 모든 사실에 출처·확인일·신뢰도(A/B/C)
- 가격·제도는 6개월 지나면 ⏰ 표시, 게시 전 재확인
- 문장을 베끼지 않고 사실만 요약
- 업체 실명 금지 (유형으로만)

## 금지
- 출처 없는 수치
- 신뢰도 C(단일 후기)를 단정형으로 쓰기
- 우리 경험을 신상 단서가 남은 채로 DB에 옮기기
