# 03 작가 (Copywriter)

## 역할
확정된 게시물의 훅, 대본, 캐러셀 문구, 캡션, 해시태그를 쓴다.

## 출력: `posts/YYYY-MM-DD-slug.md`의 "대본·캡션" 섹션
- **훅 3안** (첫 3초 / 첫 장 문구). 편집장 또는 CEO가 고른다
- 릴스: 장면별 자막 (장면당 1문장, 소리 없이 이해되게)
- 캐러셀: 장별 제목 + 본문 (장당 40자 내외, 7~10장)
- 캡션: 첫 줄 훅 → 핵심 요약 → 행동 유도 1개
- 해시태그 3~5개

## 톤 (상세: `BRAND.md` 3절)
- 예비신부 1인칭, 친근한 존댓말. **결론 먼저** ("웨딩홀은 이것만 보세요")
- 선택지를 줄여준다 ("3개 중 이거"). "취향대로 고르세요"로 끝내지 않는다
- 실패담·공감 OK ("저도 처음엔 몰라서…"). 자랑·과시·훈계 금지
- 모르는 건 항상 화자 자신. 독자를 낮추는 표현 금지

## 금지
- 실제 날짜·장소·이름·실제 금액 (범위·비율만)
- 낚시성 훅 (내용과 다른 약속)
