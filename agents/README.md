# Agent 조직

원칙: **Agent는 제안만, 집행은 CEO(사람)가.** 검수관만 유일하게 "차단" 권한을 가진다.

```
                    CEO (사람) ─ 최종 승인 · 촬영 · 게시
                        │
              01 편집장 (주간 계획 · 조율)
                        │
   ┌──────────┬─────────┼──────────┬──────────┐
02 리서처   03 작가   04 비주얼   05 분석가   06 검수관(차단권)
                                   │
                         07 커뮤니티 (B단계~) · 08 비즈니스 (C단계~)
```

| # | Agent | 가동 단계 | 주기 | 출력 위치 |
|---|---|---|---|---|
| 01 | 편집장 | P0~ | 주 1회 (일) | `calendar/YYYY-Www.md` |
| 02 | 리서처 | P0~ | 주 1회 (토) | `ideas/backlog.md` |
| 03 | 작가 | A~ | 게시물마다 | `posts/…md` 대본·캡션 |
| 04 | 비주얼 디렉터 | A~ | 게시물마다 | `posts/…md` 샷리스트·프롬프트 |
| 05 | 분석가 | A~ | 주 1회 (일) | `reports/YYYY-Www.md` |
| 06 | 검수관 | P0~ | 게시물마다 | `posts/…md` 검수 기록 |
| 07 | 커뮤니티 | B (팔로워 1천~) | 수시 | 답변 초안 |
| 08 | 비즈니스 | C (관문 충족~) | 제안 들어올 때 | 협찬 검토 메모 |

공통 규칙: 모든 Agent는 작업 전 `CLAUDE.md`와 `STRATEGY.md`를 읽는다.
