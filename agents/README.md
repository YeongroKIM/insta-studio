# Agent 조직

원칙: **Agent는 제안만, 집행은 CEO(사람)가.** 검수관만 유일하게 "차단" 권한을 가진다.

```
                    CEO (사람) ─ 최종 승인 · 촬영 · 게시
                        │
   00 기록관 (CEO가 던진 메모 → 기록 정리)
                        │
              01 편집장 (시리즈 · 제작 대상 · 게시 순서)
                        │
   ┌──────────┬─────────┼──────────┬──────────┐
02 리서처   03 작가   04 비주얼   05 분석가   06 검수관(차단권)
                                   │
                         07 커뮤니티 (B단계~) · 08 비즈니스 (C단계~)
```

| # | Agent | 가동 단계 | 주기 | 출력 위치 |
|---|---|---|---|---|
| 00 | 기록관 | P0~ | 주 1회 (일, 편집장보다 먼저) | `records/YYYY-MM.md` |
| 01 | 편집장 | P0~ | 주 1회 (일) | `calendar/YYYY-Www.md`, `queue.md` |
| 02 | 리서처 | P0~ | 주 1회 (토) | `ideas/backlog.md` |
| 03 | 작가 | R~ | 게시물마다 | `posts/…md` 대본·캡션 |
| 04 | 비주얼 디렉터 | R~ | 게시물마다 | `posts/…md` 샷리스트·프롬프트 |
| 05 | 분석가 | R~ (런칭 전엔 비축 지표만) | 주 1회 (일) | `reports/YYYY-Www.md` |
| 06 | 검수관 | P0~ | 게시물마다 | `posts/…md` 검수 기록 |
| 07 | 커뮤니티 | B (팔로워 1천~) | 수시 | 답변 초안 |
| 08 | 비즈니스 | C (관문 충족~) | 제안 들어올 때 | 협찬 검토 메모 |
| 09 | 지식관리자 | P0~ | 주 1회 (리서처 다음) | `knowledge/domains/` |

공통 규칙: 모든 Agent는 작업 전 `CLAUDE.md`와 `STRATEGY.md`를 읽는다.
