# (보류) 시그니처 포맷: "펜 한 줄 인테리어" 릴스

> ⏸ **2026-11-17 보류** — 레퍼런스와 형식이 거의 같다는 CEO 피드백. `request-reel.md`(이렇게 요청하세요)로 대체.
> 이 문서의 주제 목록(7절)·이미지 방식은 계속 쓴다.

> 레퍼런스: 해외 AI 인테리어 계정의 "기본형 → 펜으로 쓱 → 디자인 적용" 릴스 (좋아요 3,149 · **공유 1,762** · 리포스트 79).
> 형식만 참고한다. 이미지·문구는 전부 우리가 새로 만든다.

## 1. 왜 잘 되나
| 요소 | 효과 |
|---|---|
| **평범한 기본형**으로 시작 | "우리 집이랑 똑같네" — 공감 |
| **손으로 쓱 그은 선** | 무엇이 바뀔지 한눈에. 전문 용어 없이 직관적 |
| **변신 결과** | 만족감. 끝까지 보게 됨 (완주율) |
| 짧음 (8~12초) | 반복 재생 → 도달 |
| 질문형 캡션 ("어떤 게 좋아요?") | 댓글 |
| **"이렇게 하자" 공유 욕구** | 공유가 좋아요의 절반 이상 — 예비부부끼리 서로 보냄 |

## 2. 우리 버전의 차별점
레퍼런스는 **해외 고급 주택 + 그림만** 있다. 우리는:
1. **한국 아파트 기본형**에서 출발 (국평 거실 아트월, 안방 붙박이장, 현관, 주방 상부장, 복도…). "우리 신혼집도 이거네"
2. **정보 한 줄을 얹는다**: 이 디자인의 이름(예: "니치 + 간접조명"), 대략 비용 범위, 주의점 1개 → **저장 이유**가 생긴다 (지식 DB `10-interior` 기반)
3. 마지막에 다람이가 "예랑이한테 보내기 🐿️" — 공유 유도

## 3. 구성 (9:16, 10초 내외)
| 시간 | 화면 | 자막 (상단 고정, 손글씨체) |
|---|---|---|
| 0~2초 | **Before**: 한국 아파트 기본형 공간 (정지 또는 아주 느린 줌) | "평범한 안방 붙박이장" |
| 2~4초 | **손그림 선**이 그려지는 애니메이션 (바뀔 자리 표시) | "여기를 이렇게 파면" |
| 4~4.5초 | 전환 (밝아지며 교차 또는 쓸어내기) | — |
| 4.5~8초 | **After**: 같은 구도에 디자인 요소 적용 (느린 줌인) | "니치 + 간접조명 ✨" |
| 8~10초 | After 위 정보 카드 | "대략 ○○만 원대 · 상판 깊이 30cm 이상" + 🐿️ "예랑이한테 보내기" |

- 소리: 업로드 시 인스타 음원 라이브러리의 유행 음원 (저작권 안전)
- 화면 우하단 작게 **"AI 시뮬레이션"** 표기 (검수표 G — 실제 우리 집이 아님을 명확히)

## 4. 제작 파이프라인
```
① 주제 선정 ── 지식 DB 10-interior의 "디자인 요소 목록"에서 하나
② Before 이미지 ── AI 이미지 생성 (한국 아파트 기본형, 프롬프트 규칙 5절)
③ After 이미지 ── ②를 원본으로 같은 구도 유지하며 편집 (구도가 바뀌면 실패 — 다시 생성)
④ 손그림 선 ── 바뀔 영역을 따라 그린 선 (도구가 자동 생성: 영역 좌표 → 떨리는 손그림 선)
⑤ 합성 ── 도구가 Before → 선 그리기 → 전환 → After → 정보 카드를 mp4로 (ffmpeg)
⑥ 검수 ── checklists/pre-publish.md + "AI 시뮬레이션" 표기
⑦ 업로드 ── CEO가 음원 붙여 게시
```
- ②③은 Higgsfield 등 이미지 생성·편집 도구. **같은 구도 유지가 핵심**이라 "편집" 기능을 쓴다 (새로 생성 ✕)
- ④⑤는 저장소 도구로 자동화 (`tools/sketch-reel/` — 제작 예정). 사람이 할 일은 ②③ 이미지 2장 + 바뀔 영역 지정뿐

## 5. 이미지 프롬프트 규칙
- Before: "평범한 한국 신축 아파트 [공간], 흰 붙박이장/기본 아트월, 자연광, 사람 없음, 정면에 가까운 3/4 구도, 사진처럼"
- After: "같은 사진, 같은 구도·조명 유지. [디자인 요소]만 추가: …"
- 공통 금지: 창밖 고층 풍경이 특정 단지처럼 보이는 것, 로고·브랜드 제품, 사람 얼굴
- 톤: `BRAND.md`의 웜화이트·베이지·우드 (레퍼런스의 차분한 뉴트럴 톤과 같음)
