# 시그니처 포맷 2: "빈집 채우기" 릴스

> 레퍼런스: 해외 AI 인테리어 릴스 — 아무것도 없는 방이 단계별로 채워져 완성되는 과정 (좋아요 6.5만 · **공유 2.4만** · 댓글 1,845).
> 형식만 참고. 이미지·문구는 전부 새로 만든다.

## 1. 왜 잘 되나
- **빈 방 → 완성**까지 "다음엔 뭐가 생기지?"가 이어져 끝까지 봄 (완주율 ↑, 반복 재생 ↑)
- 한 단계씩 쌓이는 쾌감 (정리·변신 콘텐츠의 공통 원리)
- 저장·공유 동기: "우리 집 이 순서로 하자", "이 조합 좋다"

> ⚠️ 이 포맷도 레퍼런스와 겉모습이 비슷해지기 쉽다. **이름표 + 마지막 공정 순서 카드**(우리만의 정보)가 빠지면 만들지 않는다.

## 2. 우리 버전: 한국 아파트 "입주 전 빈집 → 신혼집"
- 출발점은 **한국 신축 아파트 입주 전 상태** (흰 벽지, 기본 마루, 샷시, 평천장) — 예비부부가 실제로 보게 될 장면
- 단계마다 **이름표 한 줄** ("천장 라인 조명", "헤링본 바닥", "우드 루버 아트월") → 인테리어 용어를 자연스럽게 배움 = 저장 이유
- 마지막 정보 카드: 이 단계 순서가 실제 **공정 순서**와 어떻게 다른지 한 줄 (지식 DB `10-interior` §5 공정 순서) + 🐿️ "예랑이한테 보내기"
- 나중에 경험형으로 확장: 실제 우리 집 1/11 비포 → 2/19 빈집 애프터 → 꾸민 애프터 (같은 포맷)

## 3. 구성 (9:16, 12~15초)
| 단계 | 화면 | 이름표 예시 |
|---|---|---|
| 0 | 빈 거실 (입주 전) | "입주 전 빈 거실" |
| 1 | 천장·조명 | "천장 라인 조명" |
| 2 | 바닥 | "헤링본 마루" |
| 3 | 벽 | "우드 루버 아트월" |
| 4 | 붙박이·수납 | "매립 수납장 + 간접조명" |
| 5 | 가구·커튼·소품 | "완성 ✨" |
- 단계당 약 1.5초 + 전환 0.6초, 전체 화면은 아주 느리게 계속 줌인
- 마지막 2초 정보 카드. 우하단 "AI 시뮬레이션" 상시

## 4. 이미지 만드는 법 (연쇄 편집)
**각 단계 = 바로 앞 단계 이미지를 넣고 하나만 추가하는 편집.** 처음부터 새로 생성하면 구도가 무너진다.
```
0 생성: 빈 거실  →  1 편집(0 입력): 천장 조명만 추가  →  2 편집(1 입력): 바닥만 교체  → … → 5
```
- 모델 `gpt_image_2_6`. 품질: 시안 medium 2k (장당 1 크레딧) / 최종 high 2k (장당 2.75)
- 편집 프롬프트 공통 머리말: "Keep everything else exactly identical — same camera, framing, perspective and lighting. Only add/change: …"
- 빈 방 프롬프트(0): "An empty living room of a newly built Korean apartment before move-in: plain white wallpaper, light basic laminate floor, flat white ceiling about 2.3m, large sliding balcony windows with white PVC frames on the right, no furniture, soft daylight" + 공통 꼬리말 (`sketch-reel-prompts.md`)
- 창밖은 흐린 하늘·나무 정도로 (특정 단지처럼 보이는 고층 풍경 피하기)
