# 웨딩플래너·박람회

## 1. 한 줄 요약
"무료" 플래너와 박람회 사은품의 비용은 결국 제휴 업체 가격 안에 들어 있으니, 박람회는 정보 수집만 하고 계약은 위약금·추가금 조건을 서면으로 받은 뒤 집에서 결정한다.

## 2. 생태계 구조

**플레이어**
- **웨딩컨설팅(결혼준비대행) 업체**: 스드메(스튜디오·드레스·메이크업)·웨딩홀 등 여러 업체와 제휴를 맺고 예비부부에게 패키지로 묶어 소개한다. 박람회를 직접 주최하는 경우가 많다. (출처 [3][6] · 2026-11-17 · B)
- **플래너**: 업체 소속 직원형과, 업체와 계약해 일하는 프리랜서형이 섞여 있다고 알려져 있다. 큰 업체는 둘을 함께 운영한다는 주장이 있으나 공식 자료는 없다. (출처 [11][12] · 2026-11-17 · C)
- **제휴 업체**: 스튜디오·드레스샵·메이크업샵·웨딩홀·예물·혼수·허니문 업체. 박람회에 부스를 내고, 컨설팅 업체 경유 고객을 받는다.
- **온라인·앱 기반 플래닝**: 가격 비교·견적 공개형 플랫폼. 업체별 단가 공개를 시도하자 기존 대형 컨설팅 쪽에서 거래 중단 압박이 있었다는 플랫폼 측 주장이 보도된 적 있다. (출처 [6] · 2026-11-17 · C)

**돈의 흐름 (보도·업계 진술 기준)**
- 예비부부 → (패키지 대금) → 컨설팅 업체/제휴 업체.
- 제휴 업체 → 컨설팅 업체/플래너: 리베이트·페이백·수수료, 광고비, 박람회 부스비 등이 보도됐다. (출처 [5][6] · 2026-11-17 · B — 2019년 보도 + 커뮤니티 진술 일치, 현재 수준은 확인 필요)
  - 웨딩홀이 컨설팅 업체에 하객 1인당 약 2,000~3,000원을 돌려준 문건이 보도됨 (출처 [5] · 2026-11-17 · C, 2019년 단일 보도)
  - 고객 정보를 먼저 넘긴 쪽에 건당 수수료를 주는 관행, 박람회 부스비 100만~300만 원 요구 진술 (출처 [6] · 2026-11-17 · C, 2019년 단일 보도)
- 박람회 무료 초대권 신청 때 적은 연락처가 참가 업체로 넘어가는 구조라는 지적이 있다. (출처 [6] · 2026-11-17 · C)
- **결론**: 소비자에게 "무료"인 플래너·박람회의 운영비는 제휴 업체가 부담하고, 그 비용은 업체 단가·추가금으로 소비자에게 돌아올 수 있다. (출처 [5][6] · 2026-11-17 · B, 비율·액수는 확인 필요)

**박람회 작동 방식**
- 주최: 주로 웨딩컨설팅 업체. 참가 업체가 부스를 내고, 방문한 예비부부에게 플래너가 배정되는 형태가 흔하다. (출처 [6][13] · 2026-11-17 · B)
- 사은품·당일 특가: 현장 계약을 끌어내는 장치. "오늘 현장 등록만" 식의 권유가 거의 모든 부스에서 나온다는 후기가 많다. (출처 [13][14] · 2026-11-17 · C)
- 법적 성격: 한국소비자원은 박람회장을 상설 영업장이 아닌 곳으로 보고, 여기서 맺은 계약을 방문판매로 해석한다 → 14일 내 청약철회 가능. (출처 [8][9] · 2026-11-17 · A)

**정부 제도 (2025~)**
- 공정거래위원회 「결혼준비대행업 표준약관」 제정·발표 (2025-04-03): 서비스 내용·가격 구체 기재, 해제·해지 시 환급·위약금 기준 명시, 대행업자 귀책으로 서비스가 바뀌면 추가비용 요구 금지, 청약철회권 명시, 지급보증보험 가입 시 고지. (출처 [2][3] · 2026-11-17 · A)
- 결혼서비스 가격표시제 (2025-11 도입): 기본서비스·선택품목·요금·위약금·환급 기준을 홈페이지·참가격·계약서 표지에 표시. 위반 시 1억 원 이하 과태료. (출처 [4] · 2026-11-17 · A)
- 표준약관은 사용 권장 기준이며, 모든 업체에 강제되는지는 확인 필요.

## 5. 진행 순서와 시기
- 일반적 순서: 웨딩홀 → 스드메 → 신혼집·혼수 → 청첩장 → 본식. 플래너·박람회는 보통 웨딩홀·스드메 결정 단계에서 만난다. (출처 [13] · 2026-11-17 · C)
- "예식 몇 개월 전에 플래너를 정해야 한다"는 공식 기준은 찾지 못함 → **확인 필요**. 웨딩홀 인기 날짜 선점 때문에 1년 전후로 시작한다는 후기가 많지만 근거 수치는 확인 필요.
- 권장 흐름 (사실 기반 정리):
  1. 상담 전: 참가격 누리집에서 지역별 평균가 확인 (출처 [4] · A)
  2. 박람회: 견적서·위약금 규정만 받아오기, 2~3곳 비교 (출처 [13][14] · C)
  3. 집에서 비교 후 계약. 박람회장에서 계약했다면 계약서 받은 날부터 14일 안에 철회 가능 (출처 [8][9] · A)
- 성수기: 4~5월 피해구제가 전년 동기 대비 56% 증가(125건→195건), 소비자원이 봄 성수기 피해예방주의보 발령 (출처 [4] · 2026-11-17 · A)

## 6. 흔한 함정 (후회 포인트)
| 함정 | 피하는 법 | 출처 · 신뢰도 |
|---|---|---|
| 박람회 당일 계약 압박 ("오늘만 이 가격") | 견적서만 받고 귀가. 계약했어도 박람회 계약은 방문판매로 보아 14일 안에 철회 가능, "환불 불가" 문구가 있어도 마찬가지 | [8][9][14] · A |
| 계약 해제 시 과다 위약금 | 결혼준비대행 피해 361건(2021.1~2023.4) 중 62.1%가 해제 거부·과다 위약금. 개시 전 해제는 총 대행요금 10%가 기준임을 알고 있기 | [1] · A |
| 청약철회 거부 | 같은 조사에서 18.8%. 철회 의사는 내용증명 등 날짜가 남는 방법으로 | [1][9] · A/B |
| 구두 약속이 계약서에 없음 | 상담 때 들은 조건(포함 항목·할인·환불)을 계약서에 직접 적어 달라고 요구 | [1] · A |
| 현금 일시불 결제 | 소비자원 권고: 신용카드 할부 결제 (할부 항변권 활용 여지) | [1] · A |
| 제휴 업체만 추천 | "제휴 안 된 업체도 진행 가능한지", "어디서 수수료를 받는지" 직접 물어보기 | [5][12] · B |
| 플래너 교체·연락 두절 | 담당자가 끝까지 같은지, 교체 시 계약 조건이 어떻게 되는지 계약 전 확인. 과거 "플래너 바뀌어 해제해도 계약금 미환급" 조항은 공정위가 불공정 약관으로 시정 | [7] · A |
| 프로모션 할인 핑계로 환급 거부 | 소비자원 사례: 예식 약 300일 전 해제에도 할인을 이유로 계약금 미환급. 할인 조건과 환불 조건을 분리해서 확인 | [4] · A |
| 개시 직전 고액 위약금 | 소비자원 사례: 예식 70일 전 해지에 총액 40%(440만 원) 요구. 시점별 위약금 표를 계약 전에 받기 | [4] · A |
| 무료 초대권 = 개인정보 제공 | 초대권 신청 시 연락처가 참가 업체로 갈 수 있음을 알고, 마케팅 동의 항목 확인 | [6] · C |
| 표준약관 미사용 업체 | 결혼준비대행업 표준약관 사용 여부, 가격표시(기본·선택·위약금) 공개 여부 확인 | [2][4] · A |

**계약서 확인 항목 (정부 자료 기반 체크리스트)**

- 업체 귀책 변경 시 추가비용 없음 (출처 [2] · A)
- 청약철회 조항, 지급보증보험 가입 여부 (출처 [2] · A)
