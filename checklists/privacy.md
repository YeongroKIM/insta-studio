# 신상 비노출 검수표

> 검수관 Agent가 모든 게시물에 적용한다. **하나라도 ❌면 게시 차단**. 예외 없음.

## A. 계정 운영 (개설 시 1회 + 분기 점검)

- [ ] 개인 번호·개인 이메일이 아닌 **전용 이메일**로 가입
- [ ] **연락처 동기화 끔** (지인에게 "알 수도 있는 사람" 추천되는 1순위 유출 경로)
- [ ] 개인 계정과 맞팔·좋아요·댓글 교류 없음
- [ ] 개인 계정과 같은 기기에서 계정 전환 사용 자제 (가능하면 기기 분리)
- [ ] 프로필에 지역·학교·회사·나이 등 특정 가능한 정보 없음
- [ ] 페이스북·스레드 연동 시 개인 계정과 연결되지 않음

## B. 인물

- [ ] 얼굴 없음 (반사면·거울·액자 속 사진 포함)
- [ ] 목소리 없음 (자막 또는 AI 음성)
- [ ] 이름·이니셜·애칭 없음 (예비신랑은 "예랑이"로만)
- [ ] 1인칭 이야기 속에 직업·나이·회사·학교·고향·사는 지역 언급 없음
- [ ] 손 특징 없음 (반지·타투·점·네일 디자인 반복 노출 주의)

## C. 장소

- [ ] **창밖 풍경 없음** (스카이라인·맞은편 동·간판 하나로 단지 특정 가능)
- [ ] 평면도는 **변형본만** (좌우 반전·단순화). 원본 평면·면적 타입명 금지
- [ ] 단지명·동호수·현관 번호·택배 송장·우편물 없음
- [ ] 위치 태그 없음, 사진 위치정보(EXIF) 제거
- [ ] 결혼식장·업체 실명 없음 ("강남 A홀" 식 표기)

## D. 시간

- [ ] **시차**: 실제 사건으로부터 최소 2주 지남 (`queue.md`의 사건 시기 확인)
- [ ] 캡션·자막에 실제 날짜 없음 (입주일·결혼식 날짜 포함)
- [ ] "지금", "오늘 시공" 등 실시간 암시 표현 없음
- [ ] 게시 시점과 어긋나는 계절 단서가 시점 추정을 돕지 않음 (예: 게시물 순서로 결혼식 날짜를 역산할 수 있는지)
- [ ] 상대 D-day 표기("결혼 3개월 전")는 가능. 단 **게시일 + D-day로 결혼식 날짜가 역산되지 않게** 그 시점과 다른 때 게시
- [ ] 본식 사진은 하객·가족 얼굴, 식장 내부 특징(시그니처 장식·홀 이름) 없음

## E. 돈

- [ ] 금액은 **범위 또는 비율** ("300만 원대", "전체의 15%")
- [ ] 소득·자산·대출 금액 없음 (범위로도 공개하지 않음)
- [ ] 화면 캡처에 계좌·카드번호·앱 계정명 없음

## F. 화면 캡처 (3D·앱·문서)

- [ ] 창 제목·탭 이름·파일명에 단지명·실명 없음
- [ ] 알림·메신저 미리보기 없음
- [ ] 3D 화면에 동호수·단지명 라벨 없음

## G. AI·출처

- [ ] AI·3D 생성 장면에 "3D 시뮬레이션" 또는 "AI 미리보기" 표기
- [ ] 타인 사진·도면·음원 미사용 (음원은 인스타 라이브러리만)
