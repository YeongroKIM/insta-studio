# 비포 촬영 계획 — 1/11 (시공 전날, 예비일 없음)

> 이 사진은 다시 못 찍는다. 런칭 1~2주차(비포 → 3D → 애프터)의 재료다.
> 같은 위치·각도로 **2/19 빈집 애프터**, **2/20 이후 꾸민 애프터**를 다시 찍는다.

## 준비물
- [ ] 휴대폰 2대 (배터리 완충) 또는 보조배터리
- [ ] 삼각대 (같은 높이 재현용)
- [ ] 줄자, 마스킹테이프 (촬영 위치 바닥 표시 — 시공 중 지워져도 사진·메모로 남김)
- [ ] 이 체크리스트

## 촬영 규칙
- **고정 높이**: 삼각대 높이 1.2m (눈높이보다 약간 낮게), 수평 맞춤
- **위치 기록**: 촬영 지점마다 "벽에서 몇 cm" 줄자로 재서 메모 + 그 지점을 찍은 사진 1장
- **창밖 금지**: 창은 커튼 없으면 프레임 밖으로 빼거나 창을 등지고 찍는다 (스카이라인 노출 = 단지 특정)
- **해상도**: 사진은 최고 화질, 영상은 4K 30fps 세로 (9:16) + 가로 (16:9) 둘 다
- **조명**: 낮 시간 (10~15시), 실내등 전부 켬 — 애프터도 같은 시간대·조명으로
- 현관 번호, 우편함, 관리사무소 안내문, 창밖 동 번호가 프레임에 들어가지 않게
