# 계정 개설·보안 설정 (1회, P0 단계)

> CEO가 직접 한다. 메뉴 이름은 인스타 앱 버전마다 다를 수 있으니 비슷한 항목을 찾는다.
> 목표: **아이디 선점 + 신상 연결 고리 끊기 + 인사이트(KPI) 준비.** 런칭(3/1) 전까지 게시물은 0개.

## 1. 가입 전 준비
- [ ] **전용 이메일** 새로 만들기 (이름·생일·회사 등이 안 들어간 주소)
- [ ] 비밀번호는 비밀번호 관리 앱에 저장 (두 사람이 같이 쓸 수 있게)

## 2. 가입
- [ ] 아이디 `@darami.bride` (불가 시 `@bride.daram`) — 결정되면 `BRAND.md` 1절 갱신
- [ ] **이메일로 가입.** 전화번호는 가능하면 등록하지 않는다
      (인증을 요구하면 등록하되 아래 3번의 "전화번호로 찾기"를 반드시 끈다)
- [ ] 연락처 접근 권한 요청 → **허용 안 함**
- [ ] 개인 계정이 있는 폰에서 추가할 때 "계정 센터에 추가할까요?" → **아니요**
      (개인 계정과 같은 계정 센터에 묶이면 추천·연결 고리가 생긴다)

## 3. 신상 연결 끊기 (가장 중요)
- [ ] **연락처 업로드(동기화) 끄기** — 계정 센터 › 내 정보 및 권한 › 연락처 업로드
- [ ] 이메일·전화번호로 나를 찾기 허용 끄기 (해당 메뉴가 있으면)
- [ ] **프로필에 계정 추천 표시 끄기** — 프로필 편집 (다른 사람 프로필의 추천 목록에 뜨지 않게)
- [ ] 활동 상태(접속 중 표시) 끄기
- [ ] 페이스북·스레드 연결 하지 않기 (수익화 단계에서 별도 판단)
- [ ] 개인 계정·지인 팔로우 금지. 같은 분야(결혼 준비) 계정 몇 개 팔로우는 OK — 탐색 탭 학습용

## 4. 프로페셔널 계정 (KPI 측정에 필수)
- [ ] 설정 › 계정 유형 › **프로페셔널 계정 → 크리에이터**로 전환 (인사이트가 열린다)
- [ ] 카테고리: "블로거" 또는 "디지털 크리에이터"
- [ ] 연락처 버튼(이메일·전화) **표시 안 함**
- [ ] 계정은 **공개** 유지 (비공개면 탐색·추천에 안 뜬다)

## 5. 보안
- [ ] 2단계 인증 켜기 (인증 앱 방식 권장)
- [ ] 로그인 알림 켜기

## 6. 프로필 (`BRAND.md` 4절)

- [ ] 소개 문구 입력 (마지막 줄 "🤖 인테리어 예시 이미지는 AI 콘텐츠예요" 포함 — `BRAND.md` 4절)
- [ ] 프로필 사진: 다람이 캐릭터 확정 전까지는 비워두거나 얼굴 없는 임시 사진 (부케 든 손 등)
- [ ] 게시물·스토리·하이라이트는 **런칭 전까지 올리지 않음**
