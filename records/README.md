# 기록 (records)

**CEO는 던지기만 하고, 정리는 기록관 Agent가 한다.**

## 1. 던지는 곳 (CEO)

| 무엇 | 어디에 | 방법 |
|---|---|---|
| 사진·영상 원본 | 전용 클라우드 앨범 (저장소 아님) | 찍고 바로 업로드. 파일명은 그대로 둬도 됨 |
| 메모·생각·결정 | `records/inbox/` | 한 줄이어도 OK. 형식 없음. 아무렇게나 |
| 견적·예산 | 원본은 클라우드, 숫자는 inbox 메모로 | 기록관이 범위로 바꿔 정리 |

`records/inbox/` 사용법: **폰 Obsidian 두 번째 vault** (확정, 개인 vault와 분리)
- 새 노트를 만들면 자동으로 `records/inbox/`에 생긴다 (`.obsidian/app.json` 설정)
- 제목·형식 없이 아무렇게나. 하루 메모 한 파일이든 생각 하나당 한 파일이든 상관없다
- **사진은 Obsidian에 붙여넣지 말고 클라우드 앨범으로.** 실수로 붙여넣어도 `_attachments/`에
  저장되고 `.gitignore`로 저장소에는 올라가지 않는다 (그 기기에만 남는다)
- 급할 땐 Claude에게 채팅으로 보내도 된다 (기록관이 inbox에 받아 적는다)

inbox 메모 예시 (아무렇게나 써도 된다):
```
바닥재 견본 3개 봄. 밝은 오크가 3D랑 제일 비슷. 평당 가격 차이 꽤 남
사진: IMG_2031~2036
```

## 2. 정리 (기록관 Agent, 주 1회)

inbox → `records/YYYY-MM.md`로 옮긴다. 정리한 inbox 파일은 `records/inbox/_done/`으로 이동 (삭제 금지).

```markdown
## 2026-12-05 · 바닥재 견본 비교
- 기둥: 집 · 게시물 가능성: 높음 (A/B 비교 릴스)
- 무엇: 견본 3종 비교, 밝은 오크 선택
- 왜: 3D 시뮬레이션과 가장 비슷, 거실 채광
- 돈: 평당 ○만 원대 (범위), 최저 대비 약 20% 비쌈
- 소재: IMG_2031~2036 (클라우드)
- 나중에 확인할 것: 시공 후 실제 색감 → 회고형 게시물
- 신상 주의: 견본 매장 간판 가리기
```

## 원칙
- 금액은 정리 단계에서 **범위로** 바꾼다 (실제 금액은 저장소에 남기지 않는다)
- 날짜는 내부 기록용. 게시물에는 옮기지 않는다
- "나중에 확인할 것"을 꼭 남긴다 → 결과를 아는 회고형 게시물의 재료가 된다
